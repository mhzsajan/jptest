   - Check that Japanese/Nepali characters display correctly
   - Verify no "?????" corruption
   - Compare questions with backup file if needed

ENCODING CRITICAL INFORMATION
==============================
All files MUST be UTF-8 with BOM (Byte Order Mark):
- ✓ UTF-8 with BOM: Correct encoding for Japanese and Nepali
- ✗ UTF-8 without BOM: May cause character issues
- ✗ ASCII/ISO-8859-1: Will corrupt Japanese/Nepali text
- ✗ Windows-1252: Not suitable for multi-language content

Nepali (नेपाली) Devanagari script specifically requires:
- UTF-8 with BOM encoding
- File saved with full character support (no ASCII stripping)
- Browser must support Unicode rendering (all modern browsers do)

 HOW TO USE THE BACKUP SYSTEM

SCENARIO 1: Questions Show As "?????" (Corrupted Characters)
──────────────────────────────────────────────────────────────

1. Identify which test is corrupted
2. Go to: backup/<test-name>-backup.txt
3. Run: .\scripts\import-questions.ps1
4. Select the backup file when prompted
5. Script regenerates: tests/<test-name>/<test-name>-data.js
6. Verify in browser: http://localhost:8000/tests/<test-name>/

SCENARIO 2: Need Manual Verification
────────────────────────────────────────

1. Open test in browser
2. Open corresponding backup file in text editor
3. Compare question text and answer keys
4. If mismatch found, use Scenario 1 restoration

────────────────────────────────────────────────

1. Use backup files as source of truth for question text

SCENARIO 4: Complete System Rebuild
──────────────────────────────────────

1. Delete corrupted test data: tests/<test-name>/*-data.js
2. Run import script on all backup files in sequence
3. Regenerate all test data files fresh from backups
4. Verify all tests work correctly in browser

================================================================================
 FOR FUTURE AI RESTORATION (AUTO-RESTORATION GUIDE)
================================================================================

When you see test questions corrupted:

1. LOCATE BACKUP
   └─ File: backup/<test-name>-backup.txt (matches test name)

2. READ BACKUP FILE
   └─ Encoding: UTF-8 with BOM
   └─ Line endings: Windows CRLF
   └─ Format: Text file with structured sections

3. PARSE CONTENT
   └─ Extract: Test metadata (title, duration, score)
   └─ Extract: Questions (text, options, answers)
   └─ Preserve: All character encoding (especially CJK/Devanagari)

4. TRANSFORM TO JAVASCRIPT
   └─ Create JavaScript object matching <test-name>Data format
   └─ Structure: { title, duration, passingScore, questions: [...] }
   └─ Each question: { text, options, correctAnswer, image, audio }
   └─ correctAnswer: 0-indexed integer (0=A, 1=B, 2=C, 3=D)

5. SAVE OUTPUT
   └─ File: tests/<test-name>/<test-name>-data.js
   └─ Encoding: UTF-8 with BOM
   └─ Verify: Valid JavaScript syntax
   └─ Test: Open in browser, check character rendering

6. VERIFY RESTORATION
   └─ Browser: Test loads correctly
   └─ Display: No "?????" corrupted characters
   └─ Questions: Match backup file exactly
   └─ Answers: All mapped correctly

See RESTORATION_GUIDE.txt for detailed technical specifications.

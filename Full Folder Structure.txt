## FOLDER ORGANIZATION SUMMARY ##

Root-Level Files:
- README.md - Main documentation (start here)
- index.html - Homepage
- Full Folder Structure.txt - This file

Documentation (/docs/):
- All markdown files centralized for easy reference
- 13 documentation files covering development, changes, and testing

Project Metadata (/project-metadata/):
- package.json - Project metadata and npm scripts
- project-metadata.json - Machine-readable project summary
- AI documentation and parsing instructions

Scripts (/scripts/):
- Main PowerShell scripts: import-questions.ps1, debug-parse.ps1, etc.
- /utilities/ subfolder: Helper scripts (Python, JavaScript) for fixing/verifying paths

Test Files (/tests/):
- 12 test categories, each with index.html and *-data.js
- Backup files (.bak) for JFT Basic tests (created on 2025-12-25)

Assets (/data/ and /images/):
- /data/js/ - Core JavaScript (main.js, test-manager.js)
- /data/css/ - Stylesheets
- /data/sound/ - All audio files (background, UI, questions)
- /images/ - All image assets (icons, question images)

## Key Features ##

Control Bar (All Pages):
- Time display with day name + 24-hour format (updates every 1 second)
- Dark mode toggle button (persists in localStorage)
- Sound toggle button (persists in localStorage)
- Home button on test pages (centered, shows warning modal)
- Go-to-top button on home page (centered, smooth scroll)

Navigation Warnings:
- Warning modal for refresh (F5, Ctrl+R, Cmd+R, browser refresh)
- Warning modal for back button press
- Warning modal for home button click
- Warning modal for header/title click (on test pages)
- Custom modal only (no browser default warnings)

Footer:
- Compact footer with creator credits
- "Download Android App" plain text link below credits
- Smart detection: Play Store on Android, APK download on others

Responsive Design:
- Mobile breakpoints: 768px, 480px
- Control bar button sizes scale appropriately
- All features work on mobile devices
